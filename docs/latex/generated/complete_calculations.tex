\chapter{SM4 DFA: Complete Numerical Calculations}
\label{chap:complete_calculations}
This chapter expands the calculations behind the preceding example. All 32 basis vectors, every Gaussian-elimination row operation, all 32 inverse-output bits, all 256 byte-input tests, and all 32 reverse key-schedule steps are printed. Values are generated from the public SM4 functions and checked before publication. Bit index 0 means the least significant bit; byte index 0 means the most significant byte. These conventions differ intentionally.
\section{Why inverse diffusion is necessary}
For an isolated fault at a last-round S-box input, the older word cancels in the ciphertext difference:
\[\Delta X_{35}=L(B)\xor L(B')=L(B\xor B')=L(\Delta B).\]
The equality uses linearity over GF(2), where addition is XOR. Consequently the attacker computes $\Delta B=L^{-1}(\Delta X_{35})$; this does not require the secret key.
\section{Forward diffusion: every rotation and XOR}
\begin{align*}B&=\hex{4F000000}\\
\operatorname{ROL}_{2}(B)&=\hex{3C000001},\\
\text{running XOR}&=\hex{4F000000}\xor\hex{3C000001}=\hex{73000001}\\
\operatorname{ROL}_{10}(B)&=\hex{0000013C},\\
\text{running XOR}&=\hex{73000001}\xor\hex{0000013C}=\hex{7300013D}\\
\operatorname{ROL}_{18}(B)&=\hex{00013C00},\\
\text{running XOR}&=\hex{7300013D}\xor\hex{00013C00}=\hex{73013D3D}\\
\operatorname{ROL}_{24}(B)&=\hex{004F0000},\\
\text{running XOR}&=\hex{73013D3D}\xor\hex{004F0000}=\hex{734E3D3D}\\
\end{align*}
Thus the observed word difference is $\hex{734E3D3D}$, even though the S-box difference affects only one byte.
